# 🌐 Ayush Sahu - Developer Portfolio

A modern, responsive, and interactive personal portfolio website showcasing my skills, projects, and journey as a BCA student and aspiring Full Stack Web Developer.

🔗 **Live Website:** https://realayushsahu-ux.github.io/portfolio/

---

## 🚀 Features

- ✨ Modern and responsive UI
- 📱 Mobile-friendly design
- 🎨 Clean and professional layout
- 🖱️ Custom animated cursor (Desktop only)
- 🍔 Responsive mobile navigation
- 🎭 Smooth AOS scroll animations
- 💼 Projects showcase
- 🛠️ Skills section
- 👨‍💻 About Me section
- 📞 Contact section
- 📄 Download Resume button
- ⚡ Fast loading and optimized
